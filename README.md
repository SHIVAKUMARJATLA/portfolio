# Shiva Kumar Jatla Portfolio

A static portfolio website designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository named `portfolio` under `SHIVAKUMARJATLA`.
2. Upload these files to the repository's default branch.
3. In **Settings → Pages**, select **Deploy from a branch**, choose the default branch and `/ (root)`, then save.
4. The site will be available at `https://shivakumarjatla.github.io/portfolio/`.

Place a copy of your résumé in the project root as `resume.pdf` before publishing, so the Resume button works.
